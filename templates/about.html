System Architecture & NLP Technical Details

Inside ResumeIQ

An end-to-end overview of ResumeIQ's natural language processing pipeline, tokenization rules, skill taxonomy, and scoring algorithm.

NLP Pipeline Overview
01

Document Ingestion

Multi-engine parser extracts text streams from PDF (pdfplumber / pypdf), DOCX (python-docx / XML zip parsing), and plain text.

02

Preprocessing & Cleaning

Whitespace normalization, unicode cleaning, bullet point standardization, and custom token preservation (e.g. C++, .NET, Node.js).

03

Information Extraction

N-gram scanning (1-gram to 4-gram) against 1,200+ skill taxonomy, regex pattern matching for contact, degrees, job titles, and metrics.

04

Scoring & ATS Evaluation

Multi-factorial scoring engine (0-100) assessing contact, skills depth, work history, quantifiable impact, and formatting density.

05

TF-IDF JD Matcher

Vectorizes candidate resume and target job description with Cosine Similarity and skill gap calculation.

Technologies & Architecture

Python 3.11+ & Flask

Clean RESTful API and server-side controller managing file uploads, routing, and scoring pipelines.

NLP & Text Processing

Custom tokenization, regular expression parsers, N-gram generators, and stopword filters without external crashing dependencies.

Scikit-Learn & TF-IDF

Term frequency-inverse document frequency vectorization and cosine similarity calculation for ATS benchmarking.

Modern Responsive UI

Vanilla JavaScript, modern CSS3 variables, glassmorphic card layouts, responsive flexbox/grid, and dark/light mode.

RESTful API Documentation
POST /api/analyze

Parses and analyzes an uploaded resume or raw text.

curl -X POST http://127.0.0.1:5000/api/analyze \
  -F "resume_file=@my_resume.pdf" \
  -F "jd_text=Optional job description..."
POST /api/match-jd

Calculates match percentage and skill gap between resume and JD.

curl -X POST http://127.0.0.1:5000/api/match-jd \
  -H "Content-Type: application/json" \
  -d '{"resume_text": "...", "jd_text": "..."}'
GET /sample/{role}

Returns sample resume text (roles: swe, data-scientist).
